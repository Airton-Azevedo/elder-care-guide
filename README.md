# Cuidar de Idosos

Site estático em três idiomas (português, inglês e espanhol) com informações para quem cuida de pessoas idosas:

- primeiros socorros
- alimentos de difícil digestão
- remédios naturais de apoio
- hábitos para manter corpo e mente saudáveis

O conteúdo é informativo e não substitui a avaliação de profissionais de saúde.

## Como usar

Abra o arquivo `index.html` no navegador. Não há dependências nem etapa de instalação.

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Para abrir direto em um idioma, use `?lang=pt`, `?lang=en` ou `?lang=es` no final do endereço.

## Estrutura

```
index.html   estrutura da página
style.css    estilos
script.js    textos nos três idiomas e troca de idioma
```

Para editar ou acrescentar textos, altere os objetos `pt`, `en` e `es` em `script.js`.
